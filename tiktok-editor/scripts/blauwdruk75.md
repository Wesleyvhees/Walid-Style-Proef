# Scripts De 75 kilo blauwdruk (klaar om op te nemen)

Ruwe versie van Wes (2026-11-09, dag 11–30, opbouw HOOK 1 pijn / HOOK 2 prikkel / BODY / HOOK 3 / CTA), herschreven volgens de regels:
hoekstapeling, hoofdtrefwoord in zin 1 of 2, max ±52 woorden (12–20 s), "een" nooit "één", loop (laatste + eerste zin = één zin,
vorm wisselt), "volg voor dag X" niet uitspreken (volg-stempel staat in beeld). Ik-bewijs: Wes ging van 110 naar 75 kilo.
Template `blauwdruk75`: per tip een label "Tip 1", "Tip 2". Status: `klaar` → `opgenomen` → `geplaatst`.
Overlap met andere series staat per dag genoemd; de invalshoek is daarom anders gekozen.
