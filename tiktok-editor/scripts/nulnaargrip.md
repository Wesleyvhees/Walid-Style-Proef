Regels: 8–12 s (±25–36 woorden), eerste zin max 6 woorden met getal of uitkomst, zinnen max 8 woorden, pieken stapelen
(piek 1 < 5 s, min. 2 soorten), waarheid vóór kort, loop (laatste + eerste zin = één zin, vorm wisselt), geen film-aanwijzingen
(talking head), pill = "Van nul naar grip dag X". Status: klaar → opgenomen → geplaatst.

## Dag 14 · Twee weken niks te zien · opgenomen (bewerkt 2026-11-10, 15,6 s; v3 toon)
Trefwoord: motivatie om door te gaan
```
Twee weken, niks te zien.
En nu wil je al stoppen?
Ik woog 110 kilo.
Denk je dat dat in twee weken wegging?
Resultaat krijg je niet cadeau.
Je verdient het. Dag na dag.
Stoppen is makkelijk.
Dus doe het moeilijke: train morgen.
Ook als je denkt:
```
In beeld: "Al [stoppen]?" · impact-woorden: STOPPEN? / 110 KILO / CADEAU / MORGEN  
Loop: "Ook als je denkt: twee weken, niks te zien."  
Pieken: pijn (0 s) → confrontatie 'al stoppen?' (±2 s) → ik-bewijs 110 kilo (±4 s) → retorische vraag (±6 s) → contrast makkelijk vs moeilijk (±11 s) → opdracht (±13 s).  
Feiten: alleen Wes' eigen 110 kg.

## Dag 15 · Je stopt om een reden · opgenomen (bewerkt 2026-11-11, 16,7 s)
Trefwoord: motivatie om door te gaan
```
HOOK (letterlijk)
Je stopt steeds om een reden.
En het is niet je motivatie.

IN JE EIGEN WOORDEN (jouw verhaal)
• Ik heb zelf twee keer mijn sportschool afgezegd.
• De derde keer schreef een vriend mij in. Toen kon ik niet meer terug.
• Nu heb ik ook niet altijd zin. Maar mijn structuur neemt het over.

ANTWOORD (letterlijk, laatste 3 s)
Het is je structuur. Bouw die eerst.
Anders:
```
In beeld: "Je stopt om [een reden]" · impact-woorden: STOPPEN / 2X AFGEZEGD / STRUCTUUR  
Loop: "Anders: je stopt steeds om een reden."  
Pieken: vraag (0 s) → ik-bewijs 2x afgezegd (±3 s) → wending: vriend schreef me in (±6 s) → contrast zin vs structuur (±9 s) → antwoord (±12 s).  
Feiten: Wes' eigen verhaal (kennis/wes-ervaringen.md, 2026-11-11).

## Dag 16 · Wat anderen vinden · klaar (nieuwe scriptvorm; ervaringsregel wacht op Wes)
Trefwoord: motivatie afvallen
```
HOOK (letterlijk)
Een ding houdt je tegen.
En het zit niet in de gym.

IN JE EIGEN WOORDEN

• Of je bent bang wat ze zeggen als jij ineens kip met rijst eet.

ANTWOORD (letterlijk, laatste 3 s)
Het is wat anderen vinden. Bewandel je eigen pad.
Onthoud dus:
```
In beeld: "Een ding houdt je [tegen]" · impact-woorden: VERGELIJKEN / BANG / EIGEN PAD  
Loop: "Onthoud dus: een ding houdt je tegen."  
Pieken: vraag (0 s) → herkenning vergelijken (±3 s) → herkenning collega's (±6 s) → ik-bewijs (±9 s) → antwoord (±12 s).  
Feiten: 'bewandel je eigen pad' is Wes' eigen zin (intro Van nul naar grip); de ervaringsregel vult Wes zelf in.
